
 # 🇮🇳 Click of India

### Explore India. Discover a new story in every season.

Click of India is an interactive website that lets users explore
India's states, culture, food, destinations and seasonal beauty.

## ✨ Features

- 🗺️ Explore Indian States
- 🌦️ Discover destinations by season
- 🎭 Explore Indian culture
- 🍛 Discover regional food
- 📍 Explore famous destinations
- 🌙 Dark / Light Mode
- 🎵 Background Music
- 📸 Interactive image galleries

## 🛠️ Built With

HTML • CSS • JavaScript
